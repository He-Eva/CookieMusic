# 前端功能导航（music-client）

> 各文件内已补充 `【功能】` 注释，本文档为总索引。路径均相对于 `music-client/src/`。

## 入口与基础设施

| 文件 | 作用 |
|------|------|
| `main.ts` | Vue 应用入口，注册 Element Plus / Router / Vuex |
| `App.vue` | 根组件，仅 `<router-view>` |
| `router/index.ts` | 全部路由 + 登录/管理员守卫 |
| `api/request.ts` | axios 封装、401 跳登录 |
| `api/index.ts` | **所有后端接口**（HttpManager） |
| `mixins/mixin.ts` | 播放、路由、登录校验等公共方法 |
| `utils/index.ts` | 日期格式化、LRC 歌词解析、播放时长显示 |

## Vuex 状态

| 文件 | 作用 |
|------|------|
| `store/index.ts` | 合并 configure / user / song 模块 |
| `store/configure.ts` | 登录 token、搜索词、侧栏、导航高亮 |
| `store/user.ts` | 用户 id、昵称、头像、是否管理员 |
| `store/song.ts` | **播放器**：当前歌、队列、进度、歌词 |

## 全局布局（带 Yin 前缀的自定义组件）

| 文件 | 作用 |
|------|------|
| `views/YinContainer.vue` | 前台外壳：顶栏+内容+播放条+音频+页脚 |
| `components/layouts/YinHeader.vue` | 顶栏导航、搜索、头像菜单 |
| `components/layouts/YinPlayBar.vue` | 底部播放条、进度、上下首 |
| `components/layouts/YinAudio.vue` | 隐藏 `<audio>`，真实播放与播放记录 |
| `components/layouts/YinCurrentPlay.vue` | 右侧「当前播放列表」 |
| `components/layouts/YinFooter.vue` | 页脚 |
| `components/layouts/YinHeaderNav.vue` | 顶栏导航项子组件 |

## 用户端页面

| 路由 | 文件 | 功能 |
|------|------|------|
| `/` | `views/Home.vue` | 首页轮播、猜你喜欢、歌单/歌手推荐 |
| `/sign-in` | `views/SignIn.vue` | 用户/管理员登录 |
| `/song-sheet` | `views/song-sheet/SongSheet.vue` | 歌单列表 |
| `/song-sheet-detail/:id` | `views/song-sheet/SongSheetDetail.vue` | 歌单详情、播放、评论、评分 |
| `/singer` | `views/singer/Singer.vue` | 歌手列表 |
| `/singer-detail/:id` | `views/singer/SingerDetail.vue` | 歌手详情与歌曲 |
| `/lyric/:id` | `views/Lyric.vue` | 歌词页 |
| `/search` | `views/search/Search.vue` | 搜索入口 |
| `/community` | `views/community/Community.vue` | 社区笔记列表 |
| `/community/detail/:id` | `views/community/CommunityDetail.vue` | 笔记详情 |
| `/personal` | `views/personal/Personal.vue` | 个人中心、播放历史 |
| `/setting` | `views/setting/Setting.vue` | 设置、改密、注销 |
