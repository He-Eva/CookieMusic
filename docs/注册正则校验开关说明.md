# 注册正则校验开关说明

## 默认（测试）

- 前端 `music-client/src/enums/validate.ts`：`USE_STRICT_SIGNUP = false`
- 后端 `ConsumerRegexConstants.java`：`STRICT_REGISTRY_ENABLED = false`

用户名、密码仅需必填；密码最少 3 位（Element Plus `min: 3`）。

## 答辩演示（严格模式）

同时改两处为 `true`，保存后**重启前端 dev 服务 + 后端 Spring Boot**：

| 文件 | 常量 |
|------|------|
| `music-client/src/enums/validate.ts` | `USE_STRICT_SIGNUP = true` |
| `src/main/java/.../constant/ConsumerRegexConstants.java` | `STRICT_REGISTRY_ENABLED = true` |

### 规则摘要

| 字段 | 正则说明 |
|------|----------|
| 用户名 | 4-20 位字母、数字、下划线 |
| 密码 | 8-32 位，至少 1 个字母 + 1 个数字 |
| 手机 | 选填；有值则须为大陆 11 位手机号 |
| 邮箱 | 选填；有值则须符合邮箱格式 |

### 演示建议

1. 严格模式开：输入 `ab` / `123` → 前端提示格式错误。
2. 输入 `demo_user` / `Abc12345` → 注册成功。
3. 用 Postman 调 `POST /user/add` 提交弱密码 → 后端返回 `R.error`（说明服务端校验）。

## 涉及页面

- `SignUp.vue`：使用 `SignUpRules`（随开关切换）；提交前须 `await form.validate()`，否则会绕过前端校验
- `PersonalData.vue`：同上（无密码表单项时不会校验密码项）

## 常见问题

**开了 `USE_STRICT_SIGNUP = true` 仍能用 `123` 注册？**

1. 后端 `STRICT_REGISTRY_ENABLED` 仍为 `false` → 接口不拦弱密码。  
2. 若前端也未报错：刷新页面并确认 `SignUp.vue` 已用 `await form.validate()`（旧代码未等待校验结果会直接提交）。
